# 핵심 인사이트 (서식3·4 본문 재료)

기준: classified.csv 4,517행(실질 4,227건) + 응답 집계 262행 + 파주시 DMZ관광 22개월. 2026-08-03 산출.

## I1. 중단은 데이터 공백으로 기록되어 있다
연도별 주관식 응답: 2021년 1,284 → 2022년 1,622 → 2023년 1,549 → **2024년 0** → 2025년 62.
2023-07-18 견학 중단이 데이터에 그대로 각인. "운영 개선을 위해 수집한 데이터"(설문지정보 원문)가 개선에 쓰이지 못한 채 잠들어 있다는 문제 정의의 출발점.

## I2. 재개 요구는 소수 의견이 아니라 지배적 신호다 (전후 비교)
주제 분포 변화(2021~23 → 2025): **REOPEN 5.1% → 33.3% (+28.2%p)**.
특별견학기(2025) 응답의 1/3이 "일반견학을 재개하라"는 요구. 장문 논증형 응답("견학 자체를 없애는 것은 낡은 행정 처리 방식… 납득할 수 있는 설명을 해야")까지 존재 — 국민 수요의 직접 증거.

## I3. 잠재 수요의 정량 지표: 견학이 없어도 설문은 계속 쌓였다
주별 응답 집계 기준 2025년 전체 설문 응답 **1,973건**, 그중 '홈페이지 만족도 설문' **1,165건**.
견학이 중단된 기간에도 홈페이지에 와서 설문까지 남긴 사람이 1천 명 이상 = 대기 수요.
결합: 파주시 DMZ평화관광 월평균 **40,064명**(22개월), **외국인 비중 76.2%** — 접경 관광의 실수요와 외국인 세그먼트 근거.

## I4. 만족도는 높다 — 문제는 '경험'이 아니라 '기회'다
감성 분포: POS 65% / SUGGEST 27% / NEG 8%. 불만보다 제안이 3배.
견학 프로그램 자체는 사랑받는 자산이며(해설 칭찬 GUIDE 1,270건=30%), 핵심 결핍은 "갈 수 없다·자주 없다·시간이 짧다"는 기회의 문제.

## I5. 재개 시 우선 개선 과제 1위는 '시간 배분' — 그리고 98%가 즉시 실행 가능
Top10 랭킹(빈도×불만강도×난이도가중) 1위 TIME(288건, score 126.1).
TIME 개선수요의 **282/288건(98%)이 OPS(운영 개선만으로 가능)** — 사진 촬영 2~3분→5분+, 장소별 체류시간 조정 등 예산 없이 재개 첫날부터 반영 가능.
2위 RESERVE(265건)는 OPS 113(취소분 재배정·통보 개선)+POLICY 150(횟수 확대) 혼재 → 단계 분리 설계.

## I6. 확장 요구는 명확히 '제도 협의' 트랙이다
COURSE(코스 확대 218건, 개선 수요 내 POLICY 165건)·REOPEN(228건)의 난이도는 압도적으로 POLICY — 유엔사 협의 사안.
따라서 재개 설계는 2단 구조가 논리적: ①운영 개선(OPS 690건 — 초기 집계 668건을 주제×난이도 교차표 검산에서 정정)은 재개 즉시, ②코스·대상 확대는 협의 로드맵으로. 이 구분 자체가 데이터에서 도출된다.

## I7. 숨은 세그먼트: 기념품·기록 수요 95건
SOUVENIR 95건(기념품샵·견학증·사진 서비스) — 방문 경험을 '소유'하고 싶은 수요.
BUDGET 난이도(53건)지만 자체 수익모델 가능성 → 운영비(견학 홈페이지 연 4.8억) 일부 상쇄 논거.

## I8. 데이터 품질 부수 발견 (개선 제안 소재)
- 개방 CSV에 군인·해설사 실명 74건 비식별 미처리 → 개방 전 비식별 프로세스 보완 제안
- '설문정보' 데이터셋은 등록 메타데이터(CSV 1개)와 실물(ZIP 내 CSV 3개) 불일치
- 주관식(주력)과 응답 집계의 설문 명칭 체계 미세 불일치 (조인 시 정규화 필요)
