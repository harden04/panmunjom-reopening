# 분류 품질 블라인드 검증 리포트

- 일자: 2026-08-03 | 방법: 이중 독립 분류(inter-rater) 방식
- 원 분류: LLM(Claude Opus) 15개 병렬 배치, taxonomy.md 기준, 4,227건
- 검증 분류: **원 분류 결과를 일절 참조하지 않은** 별도 LLM 세션이 동일 taxonomy로 층화 표본 200건을 독립 재분류 (블라인드)

## 결과

| 지표 | 일치율 | 목표 |
|---|---|---|
| 주제(topic, 13분류) | **93.5%** (187/200) | ≥85% 통과 |
| 감성(sentiment, 3분류) | **98.5%** (197/200) | — |

## 불일치 분석 (13건)

- GUIDE↔EMOTION 3건: "해설 덕분에 감동" 류 — 칭찬의 대상(해설)과 성격(정서)이 겹치는 경계 사례
- RESERVE↔REOPEN 3건: "더 자주·더 많이 견학하게 해달라" — 예약 확대와 재개 확대의 경계 사례
- 나머지 7건은 산발적 1건씩 (인접 주제 간 경계)

불일치는 전부 의미상 인접한 주제 간 경계 사례로, 오분류(무관한 주제로의 배정)는 관찰되지 않았다.
집계 영향: GUIDE·EMOTION은 Top10 랭킹 산정에서 비중이 낮고(순수 소감 계열), RESERVE·REOPEN 경계는
양쪽 모두 상위 과제로 다뤄지므로 결론(우선순위 순서)에 영향 없음.
